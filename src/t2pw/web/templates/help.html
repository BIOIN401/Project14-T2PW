Help

Three ways to start

  • Pathway name. Give a name and an organism. T2PW looks for open-access papers itself. Not every paper has open-access full text, and if too little is found the job says so.
  • PubMed IDs. Only open-access full text can be read. For a paper without it, upload the PDF.
  • PDF files. Up to {{ max_pdf_files }} files per submission, {{ max_pdf_mb }} MB and {{ max_pdf_pages }} pages each ({{ max_total_mb }} MB in total). Encrypted PDFs are refused.

A submission holds up to {{ max_items }} pathways, each with its own organism.

What happens next

Your submission is queued and the pathways run one at a time, most take 20 to 60 minutes, and a run is stopped after 90 minutes. You are taken to a private job page that updates itself. If a run fails for a temporary reason (a service did not answer) it is retried automatically, up to two more times; a run that hits the 90 minute limit is not retried. The job page lists every attempt.

Your data and the job link

There is no login. The job link is the only key to your results, so keep it private. Uploaded PDFs are stored on the server only to run your job. [TODO for the product owner: how long jobs and uploads are kept.]
