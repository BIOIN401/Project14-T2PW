About Text to Pathways

T2PW (Text to PathWhiz) reads scientific papers and drafts a metabolic or signalling pathway in PWML, the file format PathWhiz uses. Give a pathway name, PubMed IDs, or PDF files; the server returns a draft for a curator to review.
