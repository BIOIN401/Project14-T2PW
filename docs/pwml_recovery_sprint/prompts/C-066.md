  `jsonschema`, `lxml`, `python-libsbml`, `rich`, `tqdm`, `pytest`, `ruff`. **No `httpx`.**

```
.venv/Scripts/python.exe -m pip show openai   ->  Version: 3.3.1
```

**The installed `openai` 3.3.1 depends on `httpx2`, a different distribution. `httpx` is required by

reproducible from its own dependency files.**

Note also: `requirements.txt` pins `openai>=1.55.0` while **3.3.1** is installed — a major-version drift that
is the likely reason the `httpx` → `httpx2` switch went unnoticed.
