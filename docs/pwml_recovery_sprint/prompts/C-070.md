**⚠ The denominator on record is stale.** F-066 says *"21 of 148"*; F-069 says 147. **It is 153 today.** The
**21** still reproduces. **Re-measure all of these yourself** — F-068 is the standing lesson that a number

**Root cause, and it is agreed by two independent sources.** There is no `conftest.py`, `t2pw` is not
installed into the venv as an editable package, and `pytest.ini` sets no `pythonpath`. So **every test file
inserts `src` into `sys.path` itself, and 21 of them do not.** C-063's writer hit the same wall from another
direction and recorded it: *"`.venv/Lib/site-packages` carries no editable `.pth`, and `import t2pw` fails
outright with no `PYTHONPATH`."*

## 2. ⚠ MEASURE THIS FIRST — it decides whether the card is small or large

**Hypothesis, and it is only a hypothesis:** in a **multi-file** run, once any one collected file inserts
`src` into `sys.path`, every later file can `import t2pw`. So the 21 fail **only in isolation** — which is
exactly why SMOKE and all four chunks are green today, and why this has stayed invisible.

**If that is right, then `pythonpath = src` in `pytest.ini` fixes all 21 without moving a single chunk
count**, because `src` is already on the path in every multi-file run — the ini option only makes it
deterministic and earlier.

**Prove or refute it before writing the fix.** Required measurements, in this order:

1. **Confirm the 21 fail in isolation at base.** Pick at least 3 of them; collect each **alone**; paste the
   error.
2. **Confirm they pass in isolation with `pythonpath = src`.** All 21, not a sample.
3. **The decisive one — does any pinned count move?** With the fix applied, run and compare against the
   pinned numbers: **SMOKE 465**, **Chunk A 126**, **Chunk C 109**, **Chunk D 187** (core 160 + s8 4 + qb 23),
   **Chunk E 174**. On a tree carrying `.env`, the known conditional baseline is **Chunk D 185/187, core
   159/160** — do not report that as a regression.
   **Compare collected counts AND pass/fail sets, not just totals.** A count that holds while the pass set
   shifts is the failure this step exists to catch.

**If every count holds: the remedy is one line and this card is small.** Say so plainly — F-066's *"broad,
and forces deliberate re-pinning of SMOKE and all four chunks"* would then be an over-estimate, and
correcting it is a real contribution.

**If any count moves: STOP AND REPORT.** Do not re-pin anything. A moved count means `pythonpath` changes
import resolution in a way that needs its own analysis, and that is an orchestrator decision under merge
rule 4.
