## 2. R2 — three false-PASS vectors in `reviewer_evidence_route.py`

**A check that says evidence is safe when it is not is worse than no check**, because it retires the
manual habit that currently works.

1. **Probes in a subdirectory are never enumerated.** The glob is non-recursive and `is_file()` drops
   the directory **silently** — the check exits 0 with a green G11 while missing evidence entirely.
   REV-109 demonstrated it with `evidence/rev109_probes/deep_probe.py`. **This is the one that
   matters. Fix it: recurse, or at minimum WARN LOUDLY on a directory matching the stem glob.**
2. **A zero-byte file always reports `reachable`** — the empty blob oid is a universal constant, so a
   truncated or failed probe log "resolves" against any unrelated empty file in integration. Direct
   consequence of the deliberate different-path rule. **Decide and document**: either treat an empty
   blob as its own verdict, or record the limitation explicitly. **Do not silently keep it.**
3. **`--allow-empty` plus a mistyped task id is a silent pass** — it disarms the exit-3
   nothing-enumerated protection it sits beside. **Make the two independent**, or refuse the
   combination.

**For each fix, prove the vector is closed the way REV-109 proved B9 was non-vacuous: make the check
fail, then make it pass, and show both.**
