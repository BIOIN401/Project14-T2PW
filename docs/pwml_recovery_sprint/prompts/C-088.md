## 4. What the disposition must mean

`extracted_not_serialized` describes: **a defensible pathway core was extracted, and a correct scope
guard stopped the run before audit, DB mapping, freeze and PWML serialization.**

It must be set **only** when all of these hold, and you must be able to state where each is read
from:
* the pipeline executed;
* a defensible connected core was actually reached (not assumed — the record carries the core size
  and the gold floor);
* the stop was a **scope guard**, not a gate failure and not a crash;
* no PWML was written.

A run that reached `diagnostic_only` for any *other* reason must **not** acquire this disposition.
That is the anti-widening property and it needs its own test.
