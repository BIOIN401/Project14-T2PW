## Two design decisions worth preserving

**1. The Stage-0 derivation was exported, not hoisted.** The canonical derivation
(`_requested_pathway`, `_requested_organism`) lives inside `maybe_run_rag` at
`streamlit_app.py:465-473` — **below this card's floor and inside the concurrent card's range**, so
hoisting was impossible. It was exported to one shared factory and **pinned against the original by
an AST-extraction test** that evaluates both (plus the app's own `_safe_dict`) over 10 input shapes
and requires field-for-field agreement. `REV-060a` confirmed the pin binds in **both** directions.

> **Follow-up owed:** once C-042b (or its successor) lands, `maybe_run_rag:468-473` should call
> `pathway_context_from_stage_zero`, deleting the duplicate the pin currently guards.

**2. A real `PathwayContext` must be constructed at every site.** `_screen_advisory` gates on
`isinstance(context, PathwayContext)` and `PathwayContext` is a frozen dataclass, so forwarding the
Stage-0 **dict** type-checks and is **silently inert**. All three sites build the real object; a
structural test asserts it, and `REV-060a` proved by mutation that the test catches a dict
regression.

## Explicitly out of scope

**`seed_text` is not wired anywhere.** Wiring it would switch on evidence-span removal for every
Stage-2 QA round — a deliberate pinned-baseline move and a separate decision, not wiring.
**Correction to the original pack premise:** activating `pathway_context` does **not** make
`_unlocatable` load-bearing; `_unlocatable` keys off `seed_text` only. The two are independent.

## `_unlocatable` hardening — prophylactic, explicitly NEW

A fixed `str.maketrans` fold (curly quotes/apostrophes, dash family, NBSP/zero-width) applied through
a **new** `_locatable` rather than by widening `_squash` — because `_assay_marker` shares `_squash`,
so widening it would fire the composite rule on *more* rows. The fold can only make the hallucination
rule fire on **fewer**. `REV-060a` proved monotonicity empirically over 200,000 constructed cases
with 132,609 genuine base matches: **tip removes where base did not = 0**.

Because no production caller supplies `seed_text`, this code is **inert in production and cannot
carry a base-SHA behavioural failure**. It ships as an explicitly labelled NEW acceptance test and
claims no base failure. No fuzzy matching, no synonym inference, no LLM call, no chemical-name
equivalence.
