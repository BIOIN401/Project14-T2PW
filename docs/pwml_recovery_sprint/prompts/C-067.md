## 2. The real defect — verified at source by two independent readers

**The closure pruner and the degree-zero detector resolve entity names differently.**

| | code | resolution |
|---|---|---|
| **pruner** keeps a row | `strict_quarantine.py:1524-1526` — `norms = {norm for norm in _entity_name_norms([row]) if norm}` then `if norms & keep_norms` | **name ∪ synonyms** (`process_normalizer.py:626-636` adds `_normalize(row["name"])` **and** every `_normalize(synonym)`) |
| **detector** flags a row | `strict_quarantine.py:1940-1942` — `norm = _normalize(name)`; `if not norm or norm in referenced or norm in exempt: continue` | **name only** |

`keep_norms` (`:2086`) and `referenced ∪ exempt` (`:1928-1934`) are the same set, and **nothing between the
closure fixpoint (`:2124`) and the detector (`:2151`) mutates entities** — `_drop_quarantined_processes`
touches only `processes`, `_reconcile_locked_reactions` writes only top-level keys, and
`evaluate_core_coverage` takes a `Mapping` and appends only to locals.

**Therefore, on any run with `converged == True`:**

> a row the detector flags survived `_prune_entities` at a fixpoint ⟹ its primary name is not in
> `keep_norms` ⟹ its match came from a **synonym** ⟹ **the row IS referenced and the detector cannot see
> the reference.**

**The detector is the outlier.** `_build_registry` (`:632-634`) states the module's own rule: *"Synonyms
count, exactly as `validate_registry_references` counts them."* Synonyms are populated in production by
UniProt enrichment (`mapping/enrich_entities.py:1469`, `:1225`). **Admission, pruning and the registry all
count synonyms; only `_degree_zero_exports` does not.**

**What it costs:** on both `runs_verify/2026-08-18_1328/papers/PMC12096016/strict/` and
`.../PMC12452463/strict/`, the *identical* flag `[{'bucket': 'proteins', 'name': 'Isochorismatase (EntB)'}]`
with `closure_converged: True`, `minimum_core_satisfied: True`, `coverage.reasons: []` — pinning both legs at
`diagnostic_only`. Gold calls PMC12096016's graph *"a **fully connected** metabolite chain"* and marks it
`strict_exportable` (`bench/gold/pinned_v1.json`).

## 6. The regression fixture — build it exactly this way

**F-075 removed the production trigger**, so you need a synthetic fixture. The adjudication designed one and
flagged two constraints that a careless fixture would violate.

**Shape — two arms:** one accepted reaction `A → B`; one protein row whose `name` is **not** referenced and
whose `synonyms` list contains the string the reaction's `enzymes[].entity` uses; no protein complexes. Run
`_prune_entities` to fixpoint, then `_degree_zero_exports`.
* **base:** pruner keeps the row, detector flags it → the false positive.
* **tip:** pruner keeps the row, detector returns `[]`.
* **control arm:** same graph with the synonym removed → the pruner deletes the row and the detector returns
  `[]` **after** the prune. This is your non-vacuity: it proves the detector still catches a true orphan.

**⚠ Constraint 1 — DO NOT MINT AN ACCESSION.** The adjudication's own throwaway probe used `uniprot:
P00000`, caught itself, and flagged it: that is a **forged identifier**, exactly what
`placeholder_claims_real_identity` exists to catch. Use `strict_db=False` (which short-circuits at
`strict_quarantine.py:697-698` before any identity check) or the sanctioned PathBank `Unknown`-backed
placeholder. **Fabricating an accession inside a fixture for a gate that refuses fabricated accessions would
be indefensible.**

**⚠ Constraint 2 — use transparently synthetic names, NOT enterobactin.** The seam under test is **name
resolution**, not chemistry. Real biology adds no fidelity and creates a real hazard: a fixture built from
the Ent pathway can later be replayed or quoted as a pathway assertion. `Enzyme X` / synonym `ExA` /
`A → B` asserts nothing about any organism. **This is the case where an obviously artificial fixture is the
more honest choice, not the lazier one.**

**G9:** the fixture must fail behaviourally at your base (detector returns one row for a connected protein)
and pass at your tip. **Symbol absence is not proof.**
