## 2. The defect

`unknown_backed_proteins_acceptable` is a **case-wide Boolean**. `pinned_v1.json:286` sets it `true`
for **PMC12444477** alone. Its `unknown_backed_rationale` names the entities the tolerance is *for*
and, in the same sentence, the class it must **not** cover. `semantic.py:1417` reads only the Boolean:

```python
elif not case.unknown_backed_proteins_acceptable:
    findings.append({... "kind": "unknown_backed_protein_not_acceptable" ...})
```

**The rationale is parsed, round-tripped, and never enforced.** Measured
(`evidence/g11/ORCH-710/05`), the unscoped `true` excuses **seven core enzyme rows** the rationale
explicitly excludes: **LpxA, LpxD, LpxB, LpxK, WaaA, LpxL, LpxM.**
