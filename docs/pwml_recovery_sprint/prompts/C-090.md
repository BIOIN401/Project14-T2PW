takes the actor sub-entry's `entity` / `protein` / `name` and asks whether that string appears in the

**entity table**, which the function never receives:

```

span cited: "CYP51A1 catalyzes the conversion of lansterol to 4,4-dimethyl..."
```

The identity is exact. The check fires only because the wrapper's canonical name and the paper's
gene symbol share no whole token.
