## 2. The defect

C-082 made an ambiguous species rename **decline** instead of crashing the leg:

```

report["review_required"]["species"] = "species_rename_declined:AMBIGUOUS_RENAME_TARGET"
```

**But `report["ok"] = False` demotes nothing.** Both consuming seams say so in terms:

> `writer.py:2731` — *"`prefreeze_report["ok"] is False` deliberately does NOT abort. D-029 (LOCKED)
> … Acting on it is the downstream seam's job."*
> `streamlit_app.py:4930` — *"D-029, as split by D-040 §8: this seam PERSISTS and SURFACES the
> verdict. It does not act on it."*

`classify_release_status` (`src/t2pw/pipeline/release_status.py:553`) takes **no**
`prefreeze_review_required` parameter, so a declination is **release-status-neutral**.

**The observable consequence.** At base a strict leg hitting this shape **crashed**, so it could
never be `release_ready`. At the tip it proceeds and *can* reach `release_ready` while carrying two
organism rows the ladder wanted to merge. D-035 clause 8's *"must not become a successful export"*
is currently enforced only by the **other** gates and never by this channel.

**C-082 is not charged with stopping short.** Closing this needed a locked-decision extension it had
no authority to take. D-068 has now taken it.

## 3. Required behaviour — D-068, verbatim

* `prefreeze_report["ok"] = False` **with a review-required reason** demotes the result to
  `review_required`.
* Such a run **must never reach `release_ready`**.
* **Useful intact biology remains available** — the payload is not discarded (merge rule 7).
* The ambiguous rename **remains declined**; **no unsafe merge is guessed**.
* **No payload is discarded merely because the rename was ambiguous.**
* **Do not rely on unrelated gates to prevent a successful export.** Closing this channel is the
  whole point; an invariant that holds by coincidence of gate ordering is not an invariant.

**Note the asymmetry.** `report["ok"] = False` **with a review-required reason** demotes. Decide and
document what happens to an `ok = False` that carries **no** review-required reason, and justify it
from the record rather than guessing — do not silently treat the two as the same.
