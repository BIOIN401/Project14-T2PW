**Bind grammatically, not lexically.** If your fix can be defeated by a rephrase that means the same
thing, it has not closed the route — and the audit stage regenerates its rationale **every round**,

`_match_fold` replaces every run of non-alphanumerics with a single space **before** any pattern
runs, so **no `.` ever reaches the haystack**. `[^.]` excludes nothing; the construct is a **length
bound only**, and the comments claiming a sentence bound are false.

**Scope for this card: make the code say what it does. Behaviour must not move.**

- **`_match_fold` is OUT OF BOUNDS.** It is shared and calibrated. Do not touch it.

  a single consumer that sees unfolded text, STOP and report it** — then this is a live behaviour
  question, not a cosmetic one, and it is mine to re-charter.
- Note that `[^.]` also matches a newline where `.` does not. Fold collapses newlines to spaces, so
  the equivalence holds — **but prove it, don't assert it.**
- **G9:** this member carries an **explicitly labelled NEW acceptance test** pinning that folding
  strips periods and that the construct bounds length only. It has **no base failure and must not

### (c) An actor whose own NAME contains an enzyme noun licenses itself — `product_contract_violation`


**I have not measured this and you must not treat it as a design instruction.** The handoff's own

a **biological gate**. **Merge rule 6 binds: you may not weaken it to admit more rows.**

The grammatical distinction that matters is **who the attenuation is aimed at**:

- `"the inhibitor P4X catalyses …"` — appositive. P4X **is** the inhibitor. Not evidence P4X is

- `"the inhibitor of P4X was added"` — P4X is the **target**. Contra should **fire**.

C-107 already built the actor-anchored F1/F2 frames for precisely this question. **Reuse that

the diff which job each pattern now does.

**REFUSE**. `"P is an inhibitor of X"` still licenses an **inhibition** row.

**And check the blast radius:** `_ANY_ROLE_CUE_RE` is rebuilt from every value of `_ROLE_CUE_RES`,
so touching the inhibition family widens or narrows the **`other` fallback for every unmapped
role**. C-107's `test_the_other_fallback_did_not_widen_for_an_unmapped_role` pins it. It stays green.
