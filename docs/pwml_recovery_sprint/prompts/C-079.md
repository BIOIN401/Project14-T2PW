## 2. The defect, measured

C-075 Extension A fixed the **audit** LLM prompt by filtering at serialisation, keyed off
`identity_admission.SOURCE_INDEX_KEY`, using an **allow-list** constant. `audit_json_llm.py:41`:

```python
PROMPT_OMITTED_PAYLOAD_KEYS: frozenset = frozenset({
    identity_admission.SOURCE_INDEX_KEY,
})
```

and `audit_json_llm.py:1311-1318` filters on it — shallow copy, only when there is something to
filter, caller's payload never mutated.

**There is a second site with the same job and it filters the other way round.**
`curation/interactive_curator.py:164` `strip_payload_for_interactive_context` delegates to
`_strip_payload_value` (`:751`), which at `:867-869` tests:

```python
if key_lower in _RAW_TEXT_KEYS:          # exact membership
if any(token in key_lower for token in _BULKY_KEY_TOKENS):   # substring
```

`source_text_index` matches **neither**. I verified both halves rather than reading them:

* `_RAW_TEXT_KEYS` (`:122-133`) carries `source_text`, `raw_text`, `full_text`, … — **not**
  `source_text_index`.
* `_BULKY_KEY_TOKENS` (`:105-120`) is `candidate, candidates, search_result, search_results,
  match_result, match_results, enrichment, enrichment_cache, enrichment_caches, raw_enrichment,
  raw_enrichments, enrichment_raw, cache, cached`. **Not one of them is a substring of
  `source_text_index`** — tested directly, the match list comes back empty.

`run_interactive_curator_round` then `json.dumps` that payload into a multimodal prompt
(`interactive_curator.py:255-259`). F-105 measured the index blob at **64,880 bytes** on a real leg.
So once the source index is armed — and it is, since `f12115a` — roughly 65 KB of index rides into
**every interactive curator round**.

### The design point, which is the actual reason for the card

The two sites fail differently for the same reason: **one filters by an allow-list keyed off the
constant, the other by a blacklist that has to be remembered.** A blacklist silently admits every
future key. Adding one more string to `_RAW_TEXT_KEYS` fixes today's symptom and leaves the defect
class intact.

## 3. Required change

Make the interactive path consult **`PROMPT_OMITTED_PAYLOAD_KEYS`** — the same constant the audit
path already uses — rather than growing the blacklist.

Do not add `"source_text_index"` to `_RAW_TEXT_KEYS`. That is the fix this card exists to refuse.
If you conclude the constant genuinely cannot be shared (an import cycle, a layering rule), say so
in your report with the exact cycle, and propose the smallest structural alternative — for example
moving the constant to a module both already depend on. **Do not silently fall back to the
blacklist.**

Keep the existing blacklist behaviour intact: this is **additive**. Every key stripped today must
still be stripped.

## 5. Required tests

1. **G9 base-failing proof.** A payload carrying `source_text_index` produces a prompt with the
   index **absent** at your tip and **present** on base. Run on a base checkout, quote both outputs.
   **Symbol absence is not proof** — this corrects pre-existing observable behaviour.
2. **Non-vacuity — the filter must be capable of being inert and is not.** A payload carrying **no**
   omitted key serialises **byte-identically** to base. This is the property the audit-side
   docstring claims (`audit_json_llm.py:38-40`, *"a payload carrying none of these keys is
   serialized by the same object it always was"*) and the interactive side must match it.
3. **The existing blacklist still strips everything it stripped.** Enumerate `_RAW_TEXT_KEYS` and
   `_BULKY_KEY_TOKENS`, assert each is still removed. Additive, not replacing.
4. **The caller's payload is not mutated.** The object travelling on to patch application and the
   authoritative mapping run is the object that arrived. `strip_payload_for_interactive_context`
   currently `deepcopy`s; whatever you do must preserve that guarantee.
5. **The two sites cannot drift again.** Assert both paths consult the same constant object, so
   adding a key to `PROMPT_OMITTED_PAYLOAD_KEYS` filters both. Without this the card fixes one
   instance of a class it claims to close.
6. **SMOKE**, baseline **473**.
