# REV-104 / REV-105 — pass/fail criteria, fixed BEFORE the diffs exist

**Written 2026-08-29 by the Lead Orchestrator while both cards were still implementing, with no
diff visible.** § 8 of the wave charter requires this. Criteria written after a diff arrives are
criteria fitted to the diff.

**The reviewer inspects the ACTUAL DIFF, never the author's report.** A report that says a test
passes is not evidence a test passes. Reproduce it.

## REV-104 — specific to the card

C-104 is **test and evidence tooling only**. It must change **no production line**.

| # | Item | Pass condition |

| A1 | **Half 1 is about identity, not equality** | the assertion must fail under R5 (`deepcopy(dict(...))` → `dict(...)`). An `==` assertion passes for a shallow copy and is exactly the vacuous guard F-144 names. **If the author asserted equality, fail it.** |
| A2 | R5 is added to the **attack set** | so the next reviewer inherits the mutation rather than re-deriving it |

| A7 | The existing conditions were not weakened while the guard was widened | read the whole predicate, not the diff hunk alone |

## REV-105 — specific to the card, and this one touches production

C-105 changes `src/t2pw/curation/apply_audit_patch.py`. It fixes T-107's Priority-2 failure.

| # | Item | Pass condition |
|---|---|---|
| B1 | **The preservation case is real and you ran it** | an audit patch that DOES carry an evidence span naming the actor in that role must still be **accepted**. A guard rejecting both directions fails § 1's *"a technically recoverable problem must not cause a run to produce no PWML"*. **This is the single most important item in this review** |
| B2 | **"Already present in the reaction" must not count as evidence for a NEW role** | the measured defect is a protein legitimately present as an `inhibitor` being promoted to `catalyst`. **Construct that exact case yourself and confirm it is still rejected.** A guard built on entity presence would pass the very patch the card exists to reject |

| B7 | G9 base failure is **behavioural** | at `36f773c` the unevidenced patch is **accepted** and the test goes red there. Not a symbol-absence argument |
| B8 | The author's own guard **mutated by you** | force the new predicate false; the rejection test must go red. Restore byte-exact per R13 |

| B10 | The scope did not widen into research-mode retention generally | research mode is fail-open **by design** and § 12 requires research artifacts *"where possible"*. The card's question is narrower: may an **unevidenced actor role** be attached |
| B11 | `placeholder_backed_proteins` untouched | § 13 standing disagreement. Any change here is an automatic fail |
| B12 | The gold set is unchanged | `git diff` must show no `src/t2pw/bench/gold/` path |

### The B9 trap, stated plainly because it is the one most likely to be missed

C-105 makes the pipeline **reject more**. That is the safe direction. But a reviewer checking only
"did the bad patch get rejected" will not notice if the implementation also rejects legitimate
enzyme additions on other papers — which would show up as **fewer** reactions across the board and
would eventually read as a Priority-4/5 regression nobody could attribute. **B1 and B6 exist to
catch that, and both require you to run something, not to read something.**
