## 2. The case

**Paper:** PMC12505894, Gutzmann DJ et al., "Cwh8 moonlights as a farnesyl pyrophosphate phosphatase and is essential for farnesol biosynthesis in *Candida albicans*", mBio 2025, doi:10.1128/mbio.02290-25, PMID 40919816.

**Licence: CC BY**, from Europe PMC REST, checked before any recording: `"license":"cc by"`, `"isOpenAccess":"Y"`. Raw response: `docs/webserver/evidence/R26/licence/licence-PMC12505894-europepmc.json`.

Candidates rejected on licence, from the same query: PMC12657337 (cc by-nc-nd, otherwise the best scope match), PMC12096016 (cc by-nc-nd), PMC12452463 (cc by-nc), PMC3480714 (no licence reported).

**How it was picked.** A read-only scan of 216 `stage1_payload.json` files in `runs_papers/`, `runs_validation/` and `runs_verify/` (`scan_runs.py`, `scan_labels.py`):
- 182 carry scope labels. **Exactly 1 has an `out_of_scope` reaction** (chlorophyll, ORCH-759; 33 reactions; a large paper; its sister run 759p has none).
- So an unaided out-of-scope hit cannot be planned for. The model usually omits such reactions or labels them `auxiliary`.
- PMC12505894 had the shape needed: 3 reactions, one of them outside the pathway (Cwh8 on dolichyl pyrophosphate, labelled `auxiliary` in the 2026-09-16 run), Stage 2 replies of 1,061 to 8,961 chars, a strict PASS in 20 minutes.

**The scope sentence (disclose).** The topic line's requested pathway is `farnesol biosynthesis (the dolichol cycle is a different pathway: extract its dolichyl pyrophosphate dephosphorylation but label it out_of_scope)`. It reaches the model through the app's real extraction-focus box. **It was written to elicit the label.** All 6 Stage 1 draws in the recording obeyed it. The filter, the merge and everything after it then ran for real on live answers. The fixture is a test case, not a benchmark of how often the model labels on its own.

## 4. Non-default setting: the driver's scope-conflict switch

The batch driver compares Stage 0's pathway name with the requested text, and the long scope sentence is not a specialisation of `farnesol biosynthesis in Candida albicans` (`batch/scope_compat.py`), so segment 1 stopped with `scope_conflict`. The case pins the driver's own documented switch, `RAG_ELIGIBILITY_STAGE0_CONFLICT_ABORTS=false` (annotate and continue), through `SECOND_CASE["env"]`. The check is in `batch/driver.py`; neither the app nor the service reads it, and it changes no LLM request, so segment 1's answers stayed valid.

## 5. Finding: the Stage-2 prompt depends on the process hash seed

`pipeline/qa_graph.py:236,554` builds the graph QA report's components by iterating sets. Components of equal size come out in hash-seed order. The report is part of the Stage-2 prompt, so two processes given identical input can ask different prompts.

Measured: segments 2 and 3 agreed for 9 LLM answers, then differed only in the order of `compound:ergosterol` / `compound:fluconazole` and `protein:Dpp2` / `Dpp3` (`docs/webserver/evidence/R26/hash-seed-diff.txt`; 15 diff ops, same length). The first fixture replays with no misses across separate processes, so no such tie reaches its prompts.

**Handling (test-only).** This case records and replays under `PYTHONHASHSEED=0`. The seed has to be set when the interpreter starts, so the new test runs its arms in a child process (`harness.py replay`), and `record` refuses to run without it. Side effect: this test file does not need to run alone. No `src` change.

## 8. RAG: not built, options

What RAG-on needs:
- **HTTP (covered):** acquisition goes through `map_ids.HttpClient`, which is `requests.Session`, already the cassette's boundary. R2.5's note that acquisition uses urllib is inaccurate for this path; `urllib` in `map_ids` is only `quote_plus`.
- **Embeddings (not covered):** `rag/embed.py:162` calls `client.embeddings.create`, a different OpenAI resource from the one patched.
- **Vector store:** local, chromadb by default, plus `data/rag_index/embeddings_cache.json`. Both would need isolating per arm.
- **Text the fixture would store:** the full text of every paper acquisition selects, inside the `rag_prose_extraction` prompts (20 such calls in the prior run of this paper).

**Why not:** those papers are chosen at run time from Europe PMC and NCBI, and Q-R25-2 binds every text a fixture stores. PubMed abstracts and arbitrary retrieved full texts are not CC-BY by default, and I cannot verify the set in advance. Filtering retrieval by licence is a `src` change.

| option | cost |
|---|---|
| A. Keep RAG off in equivalence (current) | none. RAG stays covered only by its unit and AppTest suites (c055, `test_rag_*`) |
| B. Controlled corpus: under `tests/equivalence/`, stub acquisition to serve only this CC-BY paper, and replay embeddings | about 150 test lines, one more recording (about $0.10-0.30). Covers the RAG merge and rounds, but not real retrieval |
| C. Live RAG, verifying every retrieved paper's licence at record time and refusing the fixture otherwise | cassette extension plus a licence pass; retries likely, since one non-CC-BY paper voids a run; fixture several MB |

Recommendation: A for now, B if RAG needs to be under this gate for R5/R6.
