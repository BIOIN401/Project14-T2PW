# topics.txt -- the work list for scripts/batch_run.py
#
# One line per topic. Blank lines and everything after a "#" are ignored.
# Accepted shapes:
#
#   topic | organism | count      how many papers to take for this topic
#   topic | organism              count defaults to 3
#   topic                         no organism scoping
#   PMC4412817                    a pinned paper: fetched by id, no search
#   10.1038/nchembio.1687         a pinned DOI works too
#
# Only open-access papers with retrievable full text can be run; the rest are
# recorded in the run's skipped.json with reason "no_full_text". That is normal,
# so ask for a few more papers than you need and cap the night with --limit.
#
# NOTE: --limit is a CAP, not a target. The counts below are the real ceiling --
# raising --limit without raising these changes nothing. Observed yield is
# roughly half: the 2026-07-27 runs asked for 8 and ran 4, then asked for 8
# (--limit 30) and ran 6.
