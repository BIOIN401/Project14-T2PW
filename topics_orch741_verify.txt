#     "de novo"/"production"/"heterologous" for this reason;
#   - nanoparticle "biosynthesis" papers, which the title filter passes and
#     which contain no enzymology at all;
#   - papers whose abstract names no organism (PMC12715798 ammosamide,
#     PMC12707348 biphenomycin, PMC13454174 Iridaceae isoflavone were all

#     "bacterial" cannot become a requested_organism).

# t2pw.rag.acquire.fetch_full_text -- the same code path the run uses -- so no

# data evidence/orch741/07-fetch-verify-data.json, G11 report ORCH-741/07.
